# 踩坑清单（全部为真实事故沉淀）

> 配套 `tts-voice-qc-pipeline`。每条都是"看着不该犯、但真会犯"的坑。

## A. 测量类

| # | 坑 | 根因 | 防呆 |
|---|---|---|---|
| A1 | **假 A/B：多个片段校验和完全相同** | 浮点转 16 位整数**漏乘 32767** ⇒ 所有片段近乎静音、后处理一叠全同 | A/B 落地后先做**文件级互异校验**（校验和去重），再谈听感 |
| A2 | 分带指标测不出"闷" | 统计里混入了近静音帧、或没做归一 | 用**有声音帧**（阈值 = P95 能量 − 25dB）+ 各自以 200–4000Hz 归一 |
| A3 | "变亮了"其实是假象 | 用了**比值型**指标，分母被削小 | 比值必须并列报分带**实测值** |
| A4 | 峰值读到 1.26（文件明明是 0.89） | `ffmpeg -ac 1` 对**左右声道相同**的立体声降混 ×√2 | 实测值**直读文件**；分带相对指标不受影响 |
| A5 | 跨版本曲线整体位移、白读 | 换了切片/窗长/归一化口径 | 变化口径后**同代码重算全部历史版本** |
| A6 | 拿 5 字短句当基准，结论带歪 | <3s 短句指标不可靠 | **只在 ≥3s 的句子定标** |
| A7 | 优化目标一开始就错 | 参照取了**单份**录音（恰是离群值） | 参照取**多份均值**，并先验证参照彼此差异 |
| A8 | 滤波器完全不生效 | 想压 4–8k 却用了"低架/高架"型 | 动手前在**目标频段做单点验证**；压/抬中频段用带宽型（equalizer） |
| A9 | ffmpeg 打印 JSON 时拿不到数据 | 加了 `-v error` 把 stdout/stderr 的 JSON 吞了 | 测响度时**不加 `-v error`** |
| A10 | 用单趟 loudnorm 做对齐，导致泵动 | 动态归一污染音色对比 | 先测 `input_i`，再用**静态 volume=ΔdB** 施加 |

## B. 参数与引擎类

| # | 坑 | 结论 |
|---|---|---|
| B1 | emotion 传 `confident` / `neutral` 报错 | 只接受白名单类别（如 calm / happy / sad / angry / surprised / fearful / disgusted）；且**只有类别无强度** |
| B2 | speed 拉到 0.06 档距仍分辨不出 | 单次生成抖动 ±12% 大于档距 ⇒ **5 档降 3 档** |
| B3 | pitch 负值想"压低沉"没反应 | pitch **只能往上抬**（≈+1.37 半音/单位），负向近似无效；"沉"要靠降速 + 音强偏刚 + 语势下沉 |
| B4 | 跨句比较 intensity 得反结论 | intensity 与**内容强相关**，换句方向即反转 ⇒ 只可**同句对照** |
| B5 | 缓存命中错了 take | 缓存 key 必须包含**全部**影响生成的参数（漏了 pitch/intensity 就会拿错 take） |
| B6 | 文本对不上 | 生成前核对文本覆盖，避免"改了稿但用旧 take" |
| B7 | 采样率假设错 | 后端输出可能不是你以为的 48k；一切按实测 |
| B8 | 情绪/重音换档把音色拖走 | 情绪换档声纹差 ≤0.03（白换）、重音 −0.08~−0.11 ⇒ **表达换音色是硬代价** |

## C. 交付与协作类

| # | 坑 | 防呆 |
|---|---|---|
| C1 | 下游按老链路过一遍，定档音色被静默改掉 | 交接文档明写"**人声不得再 EQ/降噪/压缩/限幅**" |
| C2 | 换了音轨，下游拿旧字幕表铺字幕，整片对不上 | 交付时**显式声明旧时间码作废**，并附新 SRT + 时间轴 JSON + 校验和 |
| C3 | 交付差一截时长，下游整片错位 | 交接必须报**新旧时长差**，并提示卡片/HOLD/渐隐需重排 |
| C4 | 试听页在预览面板打不开 | 多半是**路径/命名不合约定**（用约定目录 + 中文同名 + viewport meta） |
| C5 | 试听页子资源 403 | 单文件预览服务只服务单文件 ⇒ 音频走**内嵌 blob**，别用相对路径 |
| C6 | 片段文件大小全一样，误判"没生成" | 音色/EQ 类 A/B 用 CBR 同长必然同字节数 ⇒ **校验用校验和，不看文件大小** |
| C7 | 批量删除被沙箱静默拦截 | 重建序列用**覆盖式 replace**，不用批量 remove |
| C8 | 只看脚本输出就以为推送成功 | 发布类操作必须**用读接口回查**确认 |

## D. 评审与流程类

| # | 坑 | 防呆 |
|---|---|---|
| D1 | 用"指标更好"去压听感 | 客观指标用来**定位**，落版**听感一票** |
| D2 | 撤掉的方案没记录，下一个人重试一遍 | "**试过并撤回**"也是结论，写进评审表黄项 |
| D3 | 新维度混进既有评审表，历史评审不可比 | 听感引入的新维度**单列**，不与原表混 |
| D4 | 用均值判定"自适应没收益" | 自适应看 **σ / 极差**，不看均值 |
| D5 | 逐句不同深度直接拼，句间跳音色 | 逐句后处理必须**时变平滑** |

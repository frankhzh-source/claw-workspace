# 迭代闭环与试听页规范

> 配套 `tts-voice-qc-pipeline`。

## 一、7 步闭环

```
① 基线测量（锁实现）
② 定位（把"差"落到物理量上）
③ 出候选（多档 A/B，同响度对齐）
④ 听感裁决（结构化回执）
⑤ 落版（写 manifest，可复现）
⑥ 同尺复核（同实现重算全版本）
⑦ 沉淀纪律（口径 / 坑 / 取舍）
```

### ① 基线测量
先量再改。基线与成品必须**同一套代码**，否则后面所有对比都是假的。

### ② 定位
一条听感 → 一个物理量。例：
- "整体鼻音重" → 分带 LTAS：100–800Hz 偏高 + 800–1200Hz 偏低；
- "听着拖" → 逐句字/分钟 + 句间静音占比；
- "像机器人" → 句末下倾幅度 + F0 跨度。

定位后**先报事实**（差多少 dB / 多少 st / 多少字每分钟），再说改法。

### ③ 出候选
- 一次**只动一根杆**（多变量同改则无法归因）；
- 至少 3 档（轻 / 中 / 强）给用户听，其中一档要**刻意过一点**，让用户能听出上界；
- **全部候选做同一响度对齐**（如整片 −16 LUFS）；
- 若是"换 take"，必须**同时提示副作用**（节奏和时长会一起变，例如 8.77s vs 7.04s）。

### ④ 听感裁决
- 每段音频配反馈按键，回执格式固定，例如：
  `整片|pick=n3` / `3-1|pick=n2` / `6-2|pick=n3`
- 用户可能"整片选一档、个别句选另一档" —— 这**恰恰是有价值的信号**，要去查那句为什么不一样（通常能在指标上找到对应的理由，例如"这句本来就是全片最轻的一档"）。

### ⑤ 落版
- 参数写进 manifest（含逐句增益表、映射系数、上限、平滑参数），保证可复现；
- 记录"承接了什么、替换了什么"（kept_from / replaces），便于回溯。

### ⑥ 同尺复核
用**同一实现**重算全部历史版本，输出对比表。要报：
- 声纹（多模型 + 均值，逐句 |Δ| 均）
- 时长 / 峰值 / 响度
- 分带实测值（不是比值）
- 逐句离散度（σ / 范围）

### ⑦ 沉淀纪律
三层记录：
1. **判读**（这一次发生了什么，含依据数据）；
2. **记忆**（跳会话可复用的结论）；
3. **规范**（可执行的纪律条款，编号递增，只增不改）。

## 二、试听页规范（A/B 页面的硬要求）

| 项 | 要求 | 为什么 |
|---|---|---|
| 响度 | 全部片段统一响度（如 −16 LUFS） | 音量差会系统性影响"哪个更好"的判断 |
| 播放 | 音频内嵌为 **blob**（base64 → Blob） | 预览服务只服务单文件，相对路径子资源会 403 |
| 互异校验 | 生成后校验**片段互异**（校验和去重） | 防"假 A/B"（见踩坑 A1） |
| 反馈按键 | 每段一组按键 + 一键复制回执 | 耳朵判断必须落成结构化数据 |
| 语境提示 | 跨配置/换 take 的片段标注"**整句听**" | 换 take 会同时改节奏与时长 |
| 命名/路径 | 用约定目录 + 与页面同名（含日期） + viewport meta | 否则预览面板打不开 |
| 页内对照 | 除整片 A/B，另挑 2–4 句**关键句**做逐句对照 | 整片听"齐不齐"，逐句听"哪句变了" |

**候选页与落地页分开**：候选页用于裁决（多档并列），落地页用于复核（选定版 + 对照 + 指标表）。

## 三、交接包规范

定稿交付给下游（视频/混音）时，一次性打包：

```
定稿音频（wav，标注采样率/声道/位深/时长/峰值）
+ 口播层 SRT（保留全部标点，审片校字用）
+ 字幕条 SRT（去句尾标点，直接做字幕带底稿）
+ 时间轴 JSON（句级 units + 段落 + 章节 + 音频规格 + 处理链说明）
+ 逐句 TSV（人读表）
+ 校验和（MD5SUMS）
+ 交接文档（含"下游不得做什么" + 旧数据作废声明 + 口径提醒）
```

交接文档必须包含四件东西：

1. **下游不得做什么**（例：人声禁再 EQ/降噪/压缩/限幅）；
2. **哪些旧数据作废**（换音轨 ⇒ 旧字幕/时间码全废）；
3. **需要下游重算什么**（新旧时长差 ⇒ 卡片/HOLD/渐隐重排）；
4. **测量口径提醒**（降混 ×√2、比值型指标陷阱）。

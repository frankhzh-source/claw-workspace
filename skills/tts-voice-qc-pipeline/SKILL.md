# TTS 语音产线与客观验收

> 来源：第03期A3 口播音频 26 版迭代（v1→v26）沉淀，2026-10-15 定稿。
> 核心主张：**主观质量也能验收，前提是先把形容词换成可测量的量，并锁死测量口径。**

## 一、什么时候用这套

- 用 TTS / 声音克隆做了口播，用户反馈"听着不对"但说不清哪里不对；
- 需要判断一版音频能不能定稿、还要不要继续改；
- 需要在多个候选 take / 多档后处理之间做听感裁决；
- 要把音频交给下游（视频/混音）前的交接打包。

## 二、铁律：先测量，后动手

**顺序不能反。** 用户的一句听感（"鼻音有点重"）是**线索**，不是**结论**；先量化到物理量，再决定改什么。

| 主观词 | 客观尺子 | 量什么 |
|---|---|---|
| 像不像本人 | 说话人声纹余弦相似度 | 多模型（如 CAM++ zh_en / zh_cn + WeSpeaker）× 本人参照 |
| 拖不拖 | 字/分钟（单句净时长口径） | 逐句净时长，**剔除句间静音** |
| 有没有起伏 | 基频 F0 分布 | 中位数 / 标准差 / P5-P95 跨度（st）——**看形状不看单一数值** |
| 闷不闷 | 有声帧分带 LTAS | 100–800Hz、800–1200Hz 相对参照的差 |
| 亮不亮 / 刺不刺 | 有声帧分带 LTAS | 2.5–4k、4–8k **实测能量**（不是比值） |
| 收尾顺不顺 | 句末下倾 | 每句尾部基频落差（st） |

**三条定调结论（实测）：**
1. **音色相似度由参数决定，几乎不由响度决定**——同句整体降 6dB，声纹分不变。用调音量解决音色问题 = 白做。
2. **声纹是唯一"一票否决"的尺子**——语气再自然，不像本人就归零。
3. **参数的收益是一次性的**——身份守参数归零后声纹一次性 +0.076，之后 20 多个版本在该轴上再无跳动 ⇒ **参数层到顶，剩下的缺口只能回录音样本层（克隆重训）解决**。

## 三、三层规范（L3a → L3s → L3b）

写作与调参分层，不要混着讨论：

| 层 | 名字 | 内容 | 判据 |
|---|---|---|---|
| L3a | 语义层 | 稿子每句的职能（提问/反转/归因/金句/CTA） | 有出处、可标注 |
| L3s | 声学层 | 语速/停顿/音高/音强/情绪**的相对量区间** | 可测量，用区间不用点 |
| L3b | 引擎层 | 具体参数值（speed / pitch / intensity / emotion） | 靠标定，档位 ≠ 实际 |

**关键：L3s 用相对量（"略高 / 平 / 略低"、"弱停 / 中停 / 强停"），L3b 才落数字。**换引擎时 L3a/L3s 不动，只重标 L3b。

## 四、引擎杠杆实测（哪些真有效）

| 杠杆 | 实测结论 |
|---|---|
| speed | ⚠️ 生效但**阶梯化 + 非单调**，单次抖动 ±12% 已大于任何可用档距 ⇒ **5 档应降到 3 档**（约 0.94 / 1.00 / 1.20），精密分档只能靠多次重录逼近 |
| pitch | ✅ **正向**生效（≈ +1.37 半音/单位）；🔴 **负向近似无效**（−2 档只动 0.07 半音）⇒ "压低沉"不能用负 pitch，只能靠降速 + 音强偏刚 + 语势下沉 |
| intensity | ✅ 生效可测；⚠️ 与**内容强相关**，换句方向即反转 ⇒ **只可同句对照，禁止跨句比数** |
| emotion | ⚠️ 只有**类别无强度**，不进能量折算；且换档对音色是**代价**（见下） |

**"表达换音色"是硬代价**（实测）：

- 情绪换档：与基准的声纹差 ≤0.03（≈没换来听感），却把音色拖走；
- 重音强化：音色相似度 −0.08 ~ −0.11；
- ⇒ **想同时要"更像本人"和"更会表达"，不能在参数层要，只能回样本层要。**

## 五、11 维度红黄绿评审（定稿评审表）

不写"整体不错"。逐维度只能落三态之一：**绿（达标·有客观读数）/ 黄（刻意取舍·写明代价）/ 红（未达标·有改进项）**。

1 整体节奏 · 2 句末下倾 · 3 重音表达 · 4 情感色彩 · 5 章节感 · 6 高音区覆盖 · 7 高频硬度 · 8 段1 切分 · 9 长句气口 · 10 咬字/数字外文 · 11 停顿时长

（听感新引入的缺陷作为**增补维度单列**，不要混进 11 维，否则破坏与历史评审的可比性。）

**纪律：把"试过并撤回"写进黄项。** 例如"重音强化：试了，音色掉 0.08~0.11，撤回"——否则下一个人会把同一个坑再踩一遍。

详细判定依据见 `references/01_客观验收指标与口径.md`。

## 六、7 步迭代闭环（可复用到任何"主观质量"生成任务）

```
① 设基线（客观测量，锁定实现）
   → ② 定位（指标的"差"指向哪个物理量）
      → ③ 出候选（多档 A/B，**必做同一响度对齐**，如 −16 LUFS）
         → ④ 听感裁决（结构化回执，一票定版）
            → ⑤ 落版（参数写进 manifest，可复现）
               → ⑥ 同尺复核（用同一实现重算全部历史版本）
                  → ⑦ 沉淀纪律（口径 / 坑 / 取舍写进规范）
```

两个决定成败的细节：

- **A/B 必须同响度**：音量差 3dB 会让人系统性觉得"更响的更好"，音色对比不成立。
- **给听感留按键**：每段音频配"选它 / 保留现状"按钮 + 一键复制回执。耳朵的判断必须变成**结构化数据**才进得了流程。

试听页规范（blob 播放 / 同响度 / 回执格式 / 文件互异校验）见 `references/03_迭代闭环与试听页规范.md`。

## 七、口径纪律（血泪版，摘 8 条，全文见 references/01）

1. **派生指标必须锁同一实现**：切片方式/窗长/归一化一换就等于换尺。跨版本对比要**用同一套代码重算所有历史版本**，不能拿旧报告的数直接比。
2. **比值型指标会被分母带着走**：削了低中频 ⇒ 分母变小 ⇒ `e(4-8k)/e(全带)` 虚假变亮。**报比值必须同时报实测分带。**
3. **电平读数不能走降混通道**：左右声道相同的立体声用默认系数降单声道会 ×√2（+3.01dB）⇒ 0.89 的峰值被读成 1.2586。**响度/峰值必须直读文件或取单声道。**
4. **短句（<3s）不能用来定标**：声学指标抖动大，只能看趋势。
5. **参照要取分布，不取单份**：单份参照可能是离群值，会把优化目标带歪。
6. **验收看分布，不只看均值**："全片统一削一刀"能把均值拉到位、却让离散度一格不动。**"平均相当"≠"分布相当"。**
7. **引擎的逐句差异是内容相关的系统性差异，不是噪声**（同一现象在"鼻音量"上极差可达 ~12dB）⇒ **一个刀口必然"轻的过削、重的欠削"，逐句对齐才到位。**
8. **逐句后处理必须时变平滑**：朴素"逐句断崖"相邻步进可达 5dB 以上，句间会跳音色；用逐块时变 biquad（状态连续），把瞬时变化率压到 ≤1 dB/0.1s。

## 八、交接纪律（交给下游时）

- 成品音频**已含全部后处理** ⇒ 必须明写"**人声不得再 EQ / 降噪 / 压缩 / 限幅**"，否则下游按老链路过一遍会静默改掉定档音色且无法归因。
- **换了音轨，旧字幕/时间码全部作废** ⇒ 交付必须显式声明，并附新的句级 SRT + 机器可读时间轴 + 校验和。
- **测量口径要一起交出去**（降混 ×√2、比值型指标的陷阱）——下游同样要量响度和亮度，不懂就会在错误读数上做决策。

## 九、踩坑速查（全清单见 references/02）

- **假 A/B**：浮点转 16 位整数漏乘 32767 ⇒ 所有片段近乎静音、校验和全同，12 个"有差别"的片段其实是同一个。**A/B 先做文件级互异校验。**
- **滤波器类型不匹配**：想压 4–8k 要用带宽型均衡器，用"低架"几乎无效（−1dB 只降 0.18dB）。动手前先在目标频段做单点验证。
- **页面打不开 ≠ 体量问题**：多半是路径/命名不合约定。
- **单文件预览服务**：相对路径的子资源会 403 ⇒ 试听页音频走内嵌（blob）。
- **测量要排除近静音帧**：静音帧会污染分带统计，必须用"有声音帧"口径并以中频归一。

## 十、成本与产物

- 纯后处理 / 换 take / 重拼 = **0 元**（take 池在盘上）；TTS 重录按字符计费（HD 档约 3.5 元/万字符）。
- 建议产物：`定稿音频 + 口播层 SRT（全标点）+ 字幕条 SRT（去句尾标点）+ 时间轴 JSON + 逐句 TSV + 校验和`。
